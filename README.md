# TRANSFLOW ERP — Survey Prototype v0.3
Static multi-page prototype for prospect validation. No build step.

Run locally : npx serve .          → http://localhost:3000
Deploy      : npx vercel           → clean URLs via vercel.json (/app/dashboard)

Single source of truth : assets/js/data.js  (every number lives here)
Nav + pages            : assets/js/shell.js (flip `soon:0` as pages ship)
